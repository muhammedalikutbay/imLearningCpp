# imLearningCpp

My C++ learning exercises. Each folder is a small Visual Studio console project that focuses on one topic.

| Project | Topic |
|---|---|
| `imLearningCpp` | Basics: vectors, functions, average calculation |
| `ConsoleApplication1` | First class with constructor, destructor and getters |
| `Class` | Classes, constructors and destructors (`Book`) |
| `Struct` | Structs with constructors and member functions |
| `Character` | Encapsulation, `protected` members and inheritance |
| `BasicInventorySystem` | Console inventory with `std::vector<std::string>` |
| `Copy Constructor` | Writing a custom copy constructor (`Weapon`) |
| `Delegating Constructor` | Constructors that call other constructors (`Enemy`) |
| `rule of three` | Destructor, copy constructor and copy assignment with raw memory |
| `static` | Static data members shared by all instances |

## Build and run

1. Open `imLearningCpp.sln` in Visual Studio 2022 (toolset v143) with the "Desktop development with C++" workload.
2. Right-click a project and choose **Set as Startup Project**.
3. Press **Ctrl+F5** to build and run it.

Console messages are in Turkish.
